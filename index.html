Bot Commands

FBI DISCORD BOT — COMMAND REFERENCE v2.0

Arrest & Warrant Commands
/arrest [user] [charges]
File an arrest log for a player. Requires Agent rank or higher.
/warrant [user] [reason]
Issue a wanted warrant. Requires Sr. Agent or above.
/clearwarrant [user]
Clear a warrant when suspect is apprehended. Logged automatically.
/searchwarrant [user]
Look up all active warrants for a specified username.
Player Info Commands
/lookup [user]
View player profile, rank, division, and criminal record.
/stats [user]
View arrest count, commendations, and activity stats.
/roster
Display the full active agent roster.
/wanted
List all active wanted reports in the server.
Admin & Moderation
/promote [user] [rank]
Promote an agent. Requires AD rank or above.
/demote [user] [rank]
Demote an agent. Requires AD rank or above.
/blacklist [user] [reason]
Permanently ban from the community. Director only.
/unblacklist [user]
Remove blacklist. Director only, requires review log.
/suspend [user] [duration]
Temporarily suspend an agent. AD or above.
Utility Commands
/ping
Check bot latency and status.
/help [command]
Display help info for a specific command.
/announce [message]
Send official announcement. Requires EAD rank.
/logsync
Sync latest arrest logs to this website. Auto-runs every hour.
